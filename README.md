## �🇧 English Version

Welcome to the source code of my professional portfolio! More than just a digital resume, this application is a **statement of Frontend Engineering excellence**. It was meticulously crafted to deliver a flawless user experience (UX) and raw performance, passing strict Core Web Vitals metrics.

### ✨ Architectural Highlights

This repository goes beyond standard React implementations, showcasing senior-level engineering patterns:

- ⚡ **Multithreading (Web Workers)**: Heavy UI computations and complex animations are offloaded to background workers, freeing the main thread to ensure a butter-smooth 60fps experience.
- 🚀 **Extreme Performance (Next.js 15)**: Leveraging Server-Side Rendering (SSR), Static Site Generation (SSG), and Edge Middleware for instantaneous TTFB (Time to First Byte).
- 🌐 **Native i18n**: Fully integrated internationalization system supporting English and Brazilian Portuguese with seamless switching and URL-based routing.
- 🎬 **Optimized Smooth Scrolling**: Custom _Lenis_ implementation carefully tuned to avoid LCP (Largest Contentful Paint) regressions.
- 🖼️ **Progressive Asset Loading**: Aggressive lazy loading, smart image handling, and strict performance budgets to keep the bundle size extremely lean.

## 🇧🇷 Versão em Português

Bem-vindo ao código-fonte do meu portfólio profissional! Mais do que um simples currículo digital, esta aplicação é uma **demonstração de excelência em Engenharia de Frontend**. Ele foi construído meticulosamente para entregar uma experiência de usuário (UX) impecável, focando em performance extrema e respeito absoluto às métricas do Core Web Vitals.

### ✨ Destaques da Arquitetura

Este repositório vai além de implementações React padrão, mostrando padrões de engenharia de nível Sênior:

- ⚡ **Multithreading (Web Workers)**: Cálculos pesados de interface e animações complexas são delegados para processos em segundo plano, liberando a thread principal para manter 60fps constantes.
- 🚀 **Performance Extrema (Next.js 15)**: Utilização agressiva de Server-Side Rendering (SSR), Static Site Generation (SSG) e Edge Middleware para um TTFB (Time to First Byte) instantâneo.
- 🌐 **i18n Nativo**: Sistema de internacionalização totalmente integrado, suportando Inglês e Português (Brasil) com trocas fluidas.
- 🎬 **Smooth Scrolling Otimizado**: Implementação customizada da biblioteca _Lenis_, ajustada rigorosamente para não degradar a métrica de LCP (Largest Contentful Paint).
- 🖼️ **Carregamento Progressivo**: Lazy loading agressivo, gerenciamento inteligente de imagens e orçamentos de performance estritos para manter os pacotes (bundles) extremamente leves.
