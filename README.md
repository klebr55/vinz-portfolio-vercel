# 🚀 Vinz - Portfólio de Engenharia de Software

Bem-vindo ao repositório do meu portfólio profissional! Este projeto foi desenvolvido com foco absoluto em **alta performance**, **acessibilidade** e **experiência do usuário (UX)**. Mais do que uma vitrine, ele reflete minha capacidade técnica na construção de aplicações modernas e complexas utilizando o ecossistema React.

## 🎯 Sobre o Projeto

Este portfólio não é apenas estático; ele demonstra técnicas avançadas de Frontend Engineering para garantir tempos de carregamento instantâneos e experiências fluidas.

**Destaques Técnicos:**

- **Sistema Multithreading (Web Workers)** para cálculo de animações complexas, desonerando a thread principal.
- **Internacionalização (i18n)** configurada nativamente, suportando múltiplos idiomas (PT-BR, EN).
- **Smooth Scrolling** usando _Lenis_ otimizado para não impactar o LCP (Largest Contentful Paint).
- **SSR e SSG** via Next.js 15, garantindo SEO e velocidades de carregamento de ponta.
- **Otimizações Extremas**: _Lazy Loading_ progressivo de imagens, quebra intencional de _bundles_, Edge Middleware da Vercel para roteamento rápido.

## 🛠️ Como rodar localmente

Clone esse projeto e instale as dependências. Recomendo o uso do `pnpm`, `npm` ou `yarn`.

```bash
# Clone o repositório
git clone https://github.com/SeuUsuario/vinz-portfolio-vercel.git

# Acesse a pasta
cd vinz-portfolio-vercel

# Instale as dependências
npm install

# Inicie o servidor em ambiente de desenvolvimento
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) com seu navegador para ver o resultado.
